## 物理

```
ω = I(q)⁻¹ ( R(t)ᵀ H0 − h_rel(q, q̇) )
```

- `I(q)` … 全身CMまわりの慣性テンソル（体幹系）。平行軸定理で毎時刻組み直す
- `h_rel` … 関節運動による相対角運動量（体幹の角速度を0としたときの全身CMまわり）
- 姿勢は quaternion を RK4 で積分。関節の角速度は姿勢の中心差分（h=1e-4）から出す
- 剛体18体（ポール込みで20体）。設計書の4体案の上位互換

## 人体セグメントパラメータ

**de Leva (1996) Table 4, male**（基準体 73.0 kg / 1.741 m）
de Leva P. *Adjustments to Zatsiorsky-Seluyanov's segment inertia parameters.*
J Biomech 29(9):1223-1230, 1996.

質量比は身長・体重（仮値 1.70 m / 65 kg）にスケールし、**身体ぶんの合計は 65.000 kg ちょうど**になる。
慣性は `I = (M·m̄)·(l·r)²`（原典の式）で、矢状/横/長軸の3軸ぶんを個別に計算している。

### なぜ Winter (2009) Table 4.1 を使わないか（自分でも確認済み）

Winter の慣性半径の3列は **C of G / Proximal / Distal** で、**同じ軸まわりの基準点違い**。
平行軸定理で一致することを確認した（大腿: √(0.323²+0.433²)=0.540 = ρ_prox、
√(0.323²+0.567²)=0.653 = ρ_dist）。つまり**長軸まわりの値が無い**ので、
ひねりを扱う本アプリでは使えない。de Leva は3軸を男女別に与えているので採用した。

## 座標・軸

体幹系：原点＝股関節中点、**+Y=体幹長軸（上）／+X=前／+Z=左**。
セグメントのローカル系も同じで、四肢は +Y が長軸。
**足だけは長軸が踵→爪先なので +X が長軸**（`longAxis:'x'`）として扱っている。
